# 奥奇传说校园卡-执行部-不休-卡片

参考游戏奥奇传说页游精灵不休形象，结合学院校园卡设计。

## 描述：

该项目仅有黑色阻焊与沉金两种颜色，在下单选择时需注意选择**黑色的阻焊颜色**，同时选择**沉金工艺**。

**复刻成本**：0；其中正面右下角白色为打印编号，如果需要去除**则需10元。**

尺寸为标准的银行卡尺寸：长 85.60 mm、宽 53.98 mm、圆角3mm；可以放进卡包和银行卡尺寸的卡套内。

内有三个文件：测试卡、NFC卡片-不休-无线圈，无功能卡片不休。

选择打样时请选择**无功能卡片不休。**

**禁止商用！**
